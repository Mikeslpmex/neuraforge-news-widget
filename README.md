# NeuraForge Web3 News Widget

Widget de noticias descentralizado y automatizado para **https://go.botcaza.ai**.

## Despliegue
1. Conecta este repositorio en **Render** como un *Static Site*.
2. Configura una clave secreta en GitHub Actions (`AI_API_KEY`) con tu API Key de Gemini para automatizar la redacción inteligente mediante IA.
3. Incrusta el widget en sitios externos usando:
```html
<div id="neuraforge-news-widget" data-partner="tu-socio"></div>
<script src="[https://tu-sitio.onrender.com/widget.js](https://tu-sitio.onrender.com/widget.js)" async></script>
